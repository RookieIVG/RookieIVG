### 🔧 What I'm working on

I build **custom integrations for Home Assistant**, bringing local hardware and Austrian data sources into the smart home. On the side I work in web development with **PHP/MySQL** and love tinkering with automations around Shelly &amp; co.

- 🏠 Home Assistant integrations (HACS, `DataUpdateCoordinator`, config flows, BLE)
- ⛽ Austrian APIs (e.g. the E-Control fuel price service)
- 🌡️ Sensors &amp; hardware wiring (BLE, DS18B20, Shelly)
- 🎨 A soft spot for clean design, SVG &amp; print
